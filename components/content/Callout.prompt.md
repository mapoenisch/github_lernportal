Accent-tinted (warm) box with a coral title and a small grid of point/counter-point items. Use to flag pitfalls, contrasts or "watch out" material.

```jsx
<Callout title="Häufige Fehler" items={[
  { title:'Zu früh pitchen', text:'Ohne Discovery kein Bedarf.' },
  { title:'Monolog', text:'Keine Rückfragen zulassen.' },
]} />
```
