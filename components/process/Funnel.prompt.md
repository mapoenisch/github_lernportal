Stacked stages that visibly narrow from top to bottom, joined by ↓, each with a letter/number tile. Built for the AIDA model and similar funnels.

```jsx
<Funnel stages={[
  { letter:'A', title:'Attention', text:'Eine auffällige Anzeige erregt Aufmerksamkeit.' },
  { letter:'I', title:'Interest', text:'Der Kunde liest über Funktionen.' },
  { letter:'D', title:'Desire', text:'Bewertungen wecken den Wunsch.' },
  { letter:'A', title:'Action', text:'Der Kunde kauft.' },
]} />
```
