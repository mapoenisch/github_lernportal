# Lernportal — UI kit

High-fidelity recreation of a **Lernportal lesson page**: the dark `SidebarNav`, a translucent breadcrumb header, and the warm reading column composed of the process/content components (`ProcessFlow`, `Funnel`, `PhaseLane`, `Cycle`, `Card`, `QuoteBlock`, `DataTable`, `TaskCard`, `Chip`, `Button`).

- `index.html` — interactive lesson view. Click lessons in the sidebar to switch between two sample lessons (1.3.1 B2B-Einkaufsprozess with a funnel + step flow, and 1.3.2 with a phase-lane mapping). Mark complete to see the progress footer move.

This is a *recreation* of the existing portal, not a new design. The ground truth is `Lernportal.dc.html` at the project root.
